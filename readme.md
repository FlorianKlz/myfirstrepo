# WhatsApp Sticker Importer

Eine Android-Anwendung zum Importieren von bis zu 2000 WhatsApp-Stickern aus WebP-Dateien.

## 📱 Features

- Automatisches Scannen von WebP-Dateien auf Ihrem Gerät
- Intelligente Organisation in Sticker-Pakete (je 30 Sticker)
- Automatische Größenoptimierung und Komprimierung
- Nahtlose WhatsApp-Integration
- Stabile Performance auch bei großen Sticker-Sammlungen (2000+)

## 🚀 Quick Start

1. **Projekt bauen**: Siehe [BUILD.md](BUILD.md)
2. **App installieren**: APK auf Android-Gerät installieren
3. **Sticker scannen**: In der App "Scan for Stickers" wählen
4. **Zu WhatsApp hinzufügen**: "Add to WhatsApp" für jedes Paket
